# Use of AI ("Super Intelligence") - disclosure

This file supports the NASA Space Apps Challenge 2026 requirement to acknowledge AI use for code, data and text.

## Tools
- **Claude Code** (Anthropic; model Claude Sonnet 5.5), used from the terminal, under the direction of the project owner.
- Other AI tools: none are recorded in this repository. Any other tool used by team members outside this repository is
  to be declared by the team in the submission form (not asserted here).

## What AI assisted or generated
| Area | AI role |
|---|---|
| Scientific engine (`firecal/`), data tools (`tools/`) | Code written by Claude Code from the team's specifications; reviewed and run by the team's developer |
| Tests (`tests/`, `web/tests/`) | Written by Claude Code |
| Web application (`web/src`) | Written by Claude Code (React/TypeScript), including interface, i18n and the Ikarus Aurora identity changes requested by the owner |
| Documentation (`README.md`, `docs/`) | Drafted by Claude Code; content reflects results actually computed |
| Deployment procedure | Assisted by Claude Code |
| Images, video, audio | **No AI-generated images, video or audio** are part of this repository. (The Ikarus Aurora logo is the owner's own artwork.) |
| Data | No data were generated by AI. NASA FIRMS/CMR and IBGE data are used as published. |

## What is human
- Choice of the challenge and the problem framing (comparing sensors without merging them).
- Scientific decisions and methodological constraints given to the AI (e.g. never sum MODIS and VIIRS, treat absence
  of detection as unknown coverage, exclude the evaluated year from the reference).
- Direction of the development, priorities, interface and presentation decisions, and acceptance of results.
- Review of the evidence and use-case fit by the team members listed in the README.

## What is NOT claimed
- No scientific validation by humans or AI beyond what is written in the README and `docs/`. No external expert review
  has taken place.
- No claim that any part was hand-programmed when it was generated with Claude Code.

## Prior material
Part of the data and an exploratory research study were prepared the day before the event (2026-11-13) in an earlier
private project of the same owner, with AI-assisted reports; see `docs/PROVENIENCIA.md`.
